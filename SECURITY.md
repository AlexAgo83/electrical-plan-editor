# Security Policy

## Supported Versions

Security fixes are handled for the latest released version of e-Plan Editor.

| Version | Supported |
| ------- | --------- |
| 1.12.x  | Yes       |
| < 1.12  | No        |

## Reporting a Vulnerability

Please do not open a public GitHub issue for a potential security vulnerability.

Use GitHub private vulnerability reporting from the repository Security tab, or open a private security advisory:

https://github.com/AlexAgo83/electrical-plan-editor/security/advisories/new

Include the affected version or commit, reproduction steps, expected impact, and any relevant logs or screenshots. Do not include production secrets, customer data, or private workspace files in the report.

Maintainers will acknowledge valid reports as soon as practical, triage the scope, and publish a security advisory or release notes once a fix is available.
